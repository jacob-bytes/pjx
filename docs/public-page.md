# 公网状态页规范

- 总览：/
- 节点详情：/?node=节点ID，可直接分享与刷新
- 不引前端路由库：筛选与详情状态全部走 URL 查询参数（History API）
- 管理端在 /admin/

## 一、总览页结构

1. 顶栏：品牌标记 + pjx + 服务状态分隔线；右侧实时/暂停切换、主题切换、管理入口
2. StatusBanner：页面第一结论（全部正常 / n 个需要关注 / n 个严重），
   role=status + aria-live，可关闭；关闭状态只存在内存，刷新后重新出现
3. KPI 四宫格（固定 112px 高，两列 / 四列响应式）：在线节点、高负载节点、
   累计流量、实时速率（内嵌中性色 sparkline）；数值字号响应式，移动端不截断
4. 工具栏：
   - 分类：一个微灰容器包住所有选项，选中项浮成白块（ToggleChip raised）
   - 即将到期：只在数量大于 0 时出现；高负载已由 KPI 覆盖，不重复
   - 分隔线区分筛选与排序
   - 排序下拉：默认 / CPU / 内存 / 流量 / 延迟 / 剩余天数；离线节点一律沉底
   - 右侧：搜索（点击展开）、只看收藏、网格 / 列表切换
5. 内容区：首次快照显示 8 个骨架卡片；空结果显示 EmptyState 与清除筛选；
   正常显示节点卡网格（1 / 2 / 3 / 4 列）或列表
6. 页脚：品牌与版权在左，数据口径说明在右；始终一行两端，
   同步时间不重复出现（顶栏已有）

## 二、节点卡

- 整卡可点击，打开节点详情；卡片有微浮起阴影与 hover 边框变化
- 标题行：状态点、节点名（可键盘聚焦的按钮）、国家码；异常状态文字升级到标题行，
  在线是常态所以不写文字
- 收藏：IconButton，aria-pressed，收藏态用品牌色
- 指标 2x2：CPU / 内存 / 硬盘 / 流量；每项是标签 + 数值 + 3px 进度条 + 明细
  （负载三元组、已用与总量）；流量数值按用量分档着色
- 三列信息行：上下行速率、今日上下行累计、剩余天数与计费
- 三网行：电信 / 联通 / 移动，各自标注运营商并按延迟分档着色
- 延迟与丢包：两个独立按钮，点开对应详情弹窗；按钮内是数值 + 历史直方图
  （40 点降采样为 20 格，取每两格最大值；6px 高、约 4px 宽、hover 显示数值与时间）
- 标签行：品牌淡蓝胶囊；在线时长靠右，紧凑写法 43d 显示为 43 天

## 三、节点详情页

- 头部：返回、状态点、节点选择器下拉（可搜索任意节点）、国家与标签、
  收藏、上一个 / 下一个
- 设备信息：一张紧凑摘要卡，按「变化频率」分两行 ——
  静态信息（系统与内核、CPU 型号与虚拟化、运行时长与最后上报、续费与剩余天数）
  在前，动态指标（内存与 Swap、硬盘、流量、负载）在后；
  动态项带进度条
- 在线状态时间轴：近 30 天，每格一天；hover / 聚焦显示日期、状态与上报次数；
  下方两个端点与图例，窄屏与宽屏都成立
- 图表控制行：时间范围（实时 / 4 小时 / 1 天 / 7 天 / 30 天 / 自定义）、
  采样点数与每点跨度说明、分组切换（资源 / 网络延迟）
- 资源分组：CPU 与负载双轴、内存与 Swap、硬盘、网络收发、TCP / UDP、进程数
- 网络延迟分组：6 条线路，颜色阶梯 + 线型双通道；丢包用底部事件带表达；
  图例可点击隐藏线路
- 数据不足时显示骨架屏（深链直接打开也有加载态）

## 四、延迟 / 丢包弹窗

- 由节点卡的延迟 / 丢包小块打开，原生 dialog 实现
- 头部：节点名 + 探测周期说明（每 90 秒一次）
- 时间范围：1 小时 / 6 小时 / 1 天 / 7 天 / 30 天，没有实时档
  （探测不是实时 ping，给实时档是撒谎）
- 延迟页签：多线路折线图 + 当前值 / 最小 / 最大 / 平均 / 波动
- 丢包页签：多线路折线 + 事件带
- 线路可逐条开关

## 五、URL 与本地状态

- URL 参数：cat（分类）、q（搜索）、fav（只看收藏）、sort（排序）、node（详情）
- 搜索逐字输入用 replaceState，不污染浏览器历史
- 非法分类等取值按白名单退回默认值
- localStorage：pjx-view（网格 / 列表）、pjx-favorites、pjx-theme、pjx-cvd
- 读写失败（隐私模式 / 配额超限）静默退回默认值

## 六、实时与可见性

- 首次订阅模拟一次快照拉取，期间显示骨架屏；加载完成前不渲染零值
- 页面隐藏时停表，回到前台补一次 tick 再恢复
- 订阅者归零时清理定时器与 visibilitychange 监听
- 顶栏三态：连接中 / 实时 · 1s / 已暂停（页面在后台）

## 七、无障碍与触控

- StatusBanner 用 aria-live；图标按钮都有 aria-label
- 收藏按钮 aria-pressed；分段控件 radiogroup / radio
- 色觉友好模式下状态点叠加形状：在线圆、告警三角、严重方块、离线短横
- 图表数值不只靠颜色区分，配合线型与文字
- 状态文字使用 -text token，保证对比度
- 触屏命中区不小于 44px（touch 变体），PC 保持紧凑

## 八、公开字段白名单

- 展示：别名、国家码、分类、标签、CPU / 内存 / 硬盘 / 流量、负载、Swap、
  TCP / UDP / 进程数、上下行速率与今日累计、三网延迟与丢包、
  在线时间轴、系统与内核、CPU 型号、虚拟化、架构、最后上报、到期与计费
- 不展示：IP、agent 版本、探测目标 URL、内部令牌

## 九、响应式

- 移动端：单列卡片、KPI 两列、工具栏换行、图例与端点分行；
  详情页图表单列
- 桌面端：卡片最多四列，内容区最大宽度 1280px
- 所有改动要先跑 npm run verify（类型 / 对比度 / 视觉回归）
